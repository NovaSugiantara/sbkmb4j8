# Candle Collection Log

## You're a candle enthusiast with a growing collection of jars, pillars, and tins — and you keep forgetting which scents you've already tried, which ones you loved, and which burned unevenly.

Build a single-page **Candle Collection Log** that lets you catalog every candle you own or have burned through. Each entry should capture:

- **Name & brand** of the candle
- **Scent notes** (e.g., cedarwood, vanilla, sea salt)
- **Status**: Unlit, Burning, or Finished
- **Rating** (1–5 flame icons or stars)
- **Personal notes** (e.g., "tunneled badly", "perfect for evenings", "gifted to mom")

The app should display all candles in a cozy card-based layout. Users can **add, edit, and delete** entries freely. A small summary bar at the top should show total candles logged and how many are currently Burning vs. Finished.

All data must persist using `localStorage` so the collection survives a page refresh. Keep the visual aesthetic warm and inviting — think amber tones, soft shadows, and a flickering-candle feel.
